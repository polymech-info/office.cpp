Meeting Notes — Product Roadmap

Date: June 15, 2024

Attendees: Alice Chen (PM), Bob Smith (Engineering), Carol Lee (Design), David Park (Sales)

 

Agenda

1. Q3 roadmap review

2. Customer feedback summary

3. Resource allocation

Q3 Roadmap Review

The team reviewed the Q3 roadmap priorities. The vector search feature has been deprioritized in favor of the enterprise SSO integration, which unblocks three large customer accounts. Alice confirmed the deadline remains end of August.

Key decisions made during this meeting:

  • Enterprise SSO integration moved to P0 priority
  • Vector search feature deferred to Q4
  • Mobile app redesign timeline extended by 2 weeks

Customer Feedback Summary

David shared findings from the last 10 enterprise customer interviews. The most common themes were:

  • Slow document processing for large files (> 50 MB)
  • Missing integration with SharePoint and OneDrive
  • Request for batch processing API

Carol noted that the UX research revealed users frequently miss the advanced search panel. Proposed solution: move the filter controls to a persistent sidebar.

Resource Allocation

Bob confirmed that two senior engineers will be reassigned from the analytics module to the SSO integration project starting next sprint. This impacts the analytics dashboard delivery, pushing it from Q3 to Q4.
